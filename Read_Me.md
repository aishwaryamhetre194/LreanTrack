1. Project Description

LearnTrack is a console-based Java application designed to manage students, courses, and student enrollments.The application provides a menu-driven interface that allows users to perform different operations.

Main Modules

1.Student Management

Add a new student.
Search for a student by ID.
Update student details.
List all students.
Deactivate a student.

2.Course Management

Add a new course.
View all courses.
Activate or deactivate a course.

3.Enrollment Management

Enroll a student in a course.
View enrollments for a particular student.
Update enrollment status to Completed or Cancelled.
-------------------------------------------------------------------------------------------------
Programming Language: Java
Java Development Kit (JDK): Java version installed on the development machine
Collections: ArrayList
Date and Time API: LocalDate
User Input: Scanner Class
Development Environment: Visual Studio Code
